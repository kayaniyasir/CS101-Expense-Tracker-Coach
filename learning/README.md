# Learn and Build Project 3

Follow the **seven steps in order** while working in NetBeans on the Java project. Each step has a short explanation, example, coding task, two concept questions, one application question, and a small demonstration checkpoint.

| Step | Guided lesson | Topic | Suggested timing |
|---:|---|---|---|
| 1 | [Start with a budget](STEP-01-start-with-a-budget.md) | Variables and arithmetic | Week 9 |
| 2 | [Validate expense rules](STEP-02-validate-expense-rules.md) | Conditions and categories | Weeks 9–10 |
| 3 | [Build a useful menu](STEP-03-build-a-useful-menu.md) | Repeating loops and options | Week 9 / revisit Week 10 |
| 4 | [Write clear methods](STEP-04-write-clear-methods.md) | Parameters and return values | Weeks 10–11 |
| 5 | [Store up to ten expenses](STEP-05-store-up-to-ten-expenses.md) | Related 1D arrays | Weeks 12–13 |
| 6 | [Search, update and summarize](STEP-06-search-update-and-summarize.md) | Operations and category totals | Weeks 12–14 |
| 7 | [Test and explain your work](STEP-07-test-and-explain-your-work.md) | Testing and showcase | Weeks 14–15 |

**One simple routine:** Read → Answer → Code → Test → Explain.

**Important:** The supplied Java class is deliberately incomplete. Each student must write meaningful source code and tests. Do not use real expense data.

After attempting questions, use [answers and reasoning](QUIZ_ANSWERS.md) to learn from errors. These practice quizzes do **not** change the official 10 marks.

See [requirements](../REQUIREMENTS.md), [testing worksheet](../TEST_PLAN.md) and [official rubric](../RUBRIC.md).
