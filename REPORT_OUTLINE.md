# CS101 Project 3 — Report outline (2–3 pages)

Use this outline for a **brief student-authored report**, not a generated final submission.

## Page 1 — Project purpose and team

- Project name and purpose (fictional budget and expenses).
- Features implemented (menu, records, search, update, summaries and validation).
- Team members and **specific source-code responsibilities**.

## Page 2 — Design and testing

- Which **parallel 1D arrays** are used and how matching indexes work.
- Four or more meaningful methods: name, parameters and return value.
- Six or more tests: normal, invalid and boundary. Record expected and **actual** output.

## Page 3 (if needed) — Results and reflection

- Screenshots of key menu operations and budget report.
- Known limitations or unfinished items.
- What each member learned and any outside assistance acknowledged according to course rules.
